About the data

Metric: Annualized temple endowment attendance per member, based on a trailing 7-day window.

Temple activity data comes from Fuller Consideration. Membership denominators are based on the membership data used by the Church Stats Python pipeline.

The current day is excluded because its temple activity data is incomplete. Each geography begins its trend when a complete 7-day source history is available.

This dashboard is a presentation layer for the data generated by the Church Stats project. It does not calculate or alter the underlying attendance methodology.
