# Church Stats — Complete continent denominators and full worldwide reference

## What this fixes

Before this release, the interactive continent and selected-group totals only used membership of geographies for which a temple observation existed. That excluded members in countries without temples and could make regions such as Africa appear to have much higher endowments-per-member rates than a full-population comparison.

This release changes the daily pipeline **and** dashboard together:

- Every country/territory in the latest **verified published membership snapshot** contributes its estimated members to its continent, including places with no recorded temple attendance. Those places contribute zero *locally recorded* sessions, but still count in the denominator.
- All 50 U.S. states contribute membership, regardless of whether a temple observation exists. The United States is not counted again as a separate country.
- The existing country/state picker is preserved. Unchecking a country or state removes its membership and locally recorded sessions from the selected group.
- The **Worldwide (reference)** trend is calculated separately, using **all observed endowments worldwide / the Church's published worldwide membership estimate**. It is not generated by adding up country memberships. This includes members in countries for which no country-specific data is published.
- The **United States (reference)** uses all 50 states' membership and endowments at U.S. temples.
- An individual country newly published with just one annual membership value contributes its single published value provisionally to continent-level aggregates (so it is not silently omitted), but its own historical per-member rate is unavailable until there are two annual figures. The methodology explains this.
- Countries without temples now appear in the dashboard's country and geography filters, with zero *locally recorded* attendance. This does **not** mean members of that country never attend temples elsewhere.
- The website methodology explains all of these rules.
- All seven-day denominators are time-matched daily-average membership, as before. The lagged (18-year children / 1-year converts) living-endowment model and automatic April statistical-report workflow are retained from the prior release.

## Verify installation

1. Commit the files to your default branch. `dashboard.js` **and** `temple_attendance_datawrapper3.py` must be updated together.
2. In **Actions**, confirm the Python validation test workflow passes.
3. Run **Update Church Stats** once manually. This is required to create `temple_attendance_output/trend_references.json`. The daily pipeline also regenerates `trend_dashboard.json` with membership-only countries and all 50 states.
4. In GitHub's **Code** tab, confirm both `temple_attendance_output/trend_dashboard.json` and `temple_attendance_output/trend_references.json` were committed by the daily workflow (or that your Pages deployment includes them). A missing `trend_references.json` will show a dashboard load error rather than silently use the wrong denominator.
5. Reload your Pages site (hard refresh if cached), choose only **Africa**, and confirm the country list now contains African countries with no temples. The selected weighted rate should include their membership and be lower than the former temple-hosting-only result, all else equal.
6. Check the **Worldwide (reference)** trend. Its denominator uses the separately reported worldwide total; the *Selected geographies* line uses only the countries and states you select, so an all-selected-group result can differ from the worldwide reference because some worldwide members lack a published country breakdown.

## Semantics and limits

- Numerator: annualized endowment sessions recorded **at temples physically inside the selected geographies**. Members can travel, so it is not a direct measure of the fraction of resident members who attended.
- Denominator: summed daily-average estimated members of all selected published-country geographies (plus selected U.S. states); countries without temples contribute members and zero recorded local sessions.
- Worldwide reference: all world sessions / *worldwide* Church membership. This is intentionally not equal to the sum of country-specific denominators when some membership isn't published by country.
- The regular daily run uses fixed annual data and never scrapes membership. The separate April workflow continues to validate and archive annual data.
- If an active temple country has no published membership count at all, the new pipeline **fails safely** rather than silently publish an incomplete continent denominator. You receive a GitHub Actions failure notification subject to your account's notification settings.
- New country names must be mappable to a continent. Current data is fully checked; an unfamiliar future country name causes a clear error instead of being dropped.
- Countries with a single known year of membership use that actual published count as a temporary *flat* aggregate assumption until a second year is available; their standalone rate is not presented as a calculated history.
- Historical trend records now include rows for all published-member countries/states on every fully observed seven-day date. This increases the dashboard JSON's size as more history accumulates; if many years of daily history are eventually included, a compact encoding would improve download performance.
